# Estiva Cervejaria — entrega v3

- [Baixar tema instalável](https://github.com/estivacervejaria/WPSite/raw/refs/heads/entrega-estiva-v3/dist/estiva-cervejaria.zip)
- [Baixar entrega completa, código, instruções e testes](https://github.com/estivacervejaria/WPSite/raw/refs/heads/entrega-estiva-v3/dist/estiva-entrega-v3.zip)

Instale o primeiro ZIP em WordPress → Aparência → Temas → Adicionar novo → Enviar tema, sem descompactar. A entrega completa não é um tema instalável: extraia-a para acessar fontes e documentação.

O Elementor Pro e sua licença não estão incluídos. Os testes utilizaram o plugin fornecido pelo usuário. Dados históricos do cardápio, contatos e imagens exigem revisão antes da publicação. O site público bloqueou o acesso automatizado; detalhes e evidências constam no pacote completo, docs/QA.md e docs/source-audit.md.
